# OnPublic

OnPublic is Onam Cloud's shared sovereign public cloud. It provides a cloud-native environment for applications and development workloads without requiring dedicated hardware.

## Good fit for

- Cloud-native services and application workloads.
- Development and test environments.
- Teams looking for a managed public-cloud experience within sovereign boundaries.

## Planning considerations

Before onboarding, identify data-residency requirements, access roles, network connections, and availability targets for each workload. Confirm quotas, supported services, and region availability with your Onam Cloud representative.
