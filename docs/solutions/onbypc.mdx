# OnBYOPC

OnBYOPC brings the Onam Cloud platform to customer-owned infrastructure in the customer's own data centre. Onam Cloud helps set up, configure, and manage the private cloud environment.

## Good fit for

- Organizations with existing data-centre infrastructure.
- Workloads that require local deployment or greater infrastructure control.
- Teams that want platform expertise while retaining their own hardware.

## Planning considerations

Review hardware compatibility, capacity, network topology, data-centre operations, and responsibilities for ongoing support before implementation. Confirm the supported infrastructure specifications with Onam Cloud for your design.
