# OnPrivate

OnPrivate is a dedicated private cloud set up and operated for an organization in Onam Cloud data centres. The environment is single-tenant and isolated.

## Good fit for

- Regulated workloads and enterprise platforms.
- Organizations that need a dedicated environment.
- Workloads with specific infrastructure or operational requirements.

## Planning considerations

Define capacity, data placement, network connectivity, identity integration, backup expectations, and recovery objectives with the teams responsible for the environment. Deployment scope and service details depend on the agreed design.

Compare [deployment models](../platform/choose-deployment-model.mdx) and contact the Onam Cloud team to discuss an environment tailored to your requirements.
