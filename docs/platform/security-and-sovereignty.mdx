# Security and Sovereignty

Onam Cloud is designed around control of infrastructure location, data residency, and operational boundaries. Sovereignty requirements should be considered alongside the security controls and operating practices for each workload.

## Plan for your requirements

- **Data location:** identify where data may be stored and processed, including backups and logs.
- **Access:** define administrator, operator, and application access using least privilege.
- **Network boundaries:** document connectivity between workloads, users, and external services.
- **Encryption:** confirm encryption controls for data at rest and in transit for the selected service.
- **Audit and operations:** establish logging, monitoring, incident contacts, and review responsibilities.

Onam Cloud describes centralized identity and access controls, encryption for data at rest and in transit, and monitoring, logging, and auditability as platform principles. Exact configuration and evidence depend on the deployment and service agreement.

## Compliance

Compliance obligations depend on your organization, workload, and applicable regulation. Map controls to your own requirements and request current service documentation from Onam Cloud before making compliance or certification claims.

For deployment-specific guidance, [contact the Onam Cloud team](https://onamcloud.com/contact).
